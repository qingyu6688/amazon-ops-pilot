## 授权与内容绑定

计划摘要包括任务、模式、卖家、站点、区域、SKU、完整请求体、Schema 校验和、配置摘要、确认的警告及期限。发布只传 planId，工具不能临时换正文。

disabled 无生产写入。approval 检查本机操作者创建的一次性授权；bounded 检查已配置的范围。两者都检查所有常规报价的价格、币种、站点与所有库存数量之和。出现不支持的促销/折扣字段直接拒绝，不猜测价格。

计划内的 Amazon 预览结果不是法律或事实证明。商品的品牌、材质、图片权利、认证和合规由主技能依据实际资料核查，工具只证明请求及数据检查结果。

## 发送与恢复

发布前重新检查参与站点、SKU 不存在、定义未变及预览；网络检查后再次检查期限。先持久化 submitting 与次数，再发一次。ACCEPTED 必须有 submissionId；明确 INVALID 记录 invalid；网络、解析或不确定响应记录 unknown。

submitting/unknown/accepted 会阻止同一任务另建计划；同一卖家、站点、SKU 不能建立重复任务。正式 HTTP 写入不自动重试。进程在请求后、落盘前崩溃会保留 submitting，不会重发。

首版对 unknown/submitting 不自动恢复写入。由操作者在卖家后台及 Listing 回读中核对，对状态修复需审阅实际平台证据和本地审计；不提供一个让 Agent 直接清除去重的按钮。若确需人工修复，应停止进程、备份状态并记录更改依据，而不是删除整个状态目录重跑。

## 规则校验

实时 PTD 按卖家、站点、商品类型获取 LATEST、LISTING、ENFORCED；下载链接限 Amazon HTTPS 域且禁止重定向，内容做 Base64 MD5 校验。本地 AJV 2019-09 不实现全部 Amazon 自定义词汇，因此必须继续执行平台预览。发布前定义变化会使原计划失效。

合规资料默认 7 天有效、计划默认 15 分钟、启动回读需 5 分钟内。这些都是项目控制策略，不是官方统一规定。合规过期通过独立复核工具更新，不能假改日期。

## 限流和错误

读取及预览对 429/部分 5xx 最多尝试 3 次，延迟有上限。真实写入仅一次。20 秒请求超时，响应上限 8 MiB。LWA 短期令牌内存缓存，认证/HTTP 错误不返回原始响应或凭据。未知内部错误不暴露堆栈。

## 单机边界

所有写入在同一模式目录锁内串行执行。配置/状态有本机文件权限但不是沙箱；可信本机 Agent 若能任意执行 shell 或改文件，技术上能改变这些规则。因此多用户服务端部署必须另外实现身份、授权管理和秘密托管。

Amazon 的 PUT 没有本项目可用的“只在 SKU 不存在时创建”原子前提；先查再发有竞争窗口。生产需避免其他系统/人员同时操作同一 SKU。
