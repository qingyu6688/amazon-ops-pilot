# 测试报告

版本 1.0.0，记录日期 2026-11-14。

## 验证方法

仓库根目录运行 npm run check。npm test 的 pretest 先编译程序与测试，再用 Node 自带测试运行器执行。协议测试启动实际 dist/server.js 子进程，以官方 MCP Client 连接、发现工具并调用。HTTP 合约测试注入内存响应，不连接 Amazon。测试运行不依赖原生打包器。

## 已覆盖

| 领域 | 验证重点 |
| --- | --- |
| 阶段 | 不能跳过前置、不能重复任务、证据格式与来源、合规复核 |
| 接收和可售 | 草稿不算接收，接收后仍须回读 BUYABLE |
| 权限 | 禁写、一次性授权、数量/价格/币种/站点与额外折扣限制 |
| 内容绑定 | 正文篡改、配置变化、计划过期、定义变化、未复核警告 |
| 去重 | 同计划、同任务多草稿、未知提交、日次数限制 |
| HTTP | LWA 缓存、官方区域头部、只读限流重试、正式写入不重试 |
| 定义 | 下载域名限制、内容校验和流程、本地必填检查 |
| 本地 | 锁互斥、损坏状态不覆盖、模拟/生产隔离、用户技能联接逃逸 |
| 计算 | 单件贡献、补货需求、零销量口径 |
| MCP | 实际 stdio 发现工具、模拟发布回读、错误结果及无自授权工具 |

当前本机自动化测试：35 项通过。lint 与 TypeScript 编译通过，技能与本地文档链接验证通过，官方源干净安装成功。本地模拟演示到达 operations。交付前以最终命令输出和 GitHub Actions 结果为准。

## 实际限制

没有用户的 Amazon 应用或卖家凭据，未做生产 API、真实类目、真实 FBA/广告或真实上架验证。模拟不是 Amazon Sandbox，HTTP 合约测试不能证明所有服务端行为。JSON Schema 自定义词汇、图片像素、IP 与认证真实性依然需要平台预览及实际材料。

GitHub CI 设计覆盖 Ubuntu/Windows、Node 22/24，使用无凭据测试与模拟。不会为通过测试降低生产写入控制。
