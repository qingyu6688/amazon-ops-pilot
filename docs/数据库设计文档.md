# 数据库设计文档

首版无数据库，不需要 MySQL。单机状态保存在配置文件同目录的 `.amazon-ops/<mode>/store.json`，模拟与生产物理分目录。

## 数据实体

| 实体 | 主要字段 | 用途 |
| --- | --- | --- |
| Run | id、mode、sellerId、marketplaceId、sku、stage、evidence、createdAt、updatedAt | 阶段与证据 |
| Plan | id、runId、body、schemaChecksum、preview、digest、expiresAt、status | 绑定内容的发布计划 |
| Approval | planId、digest、approvedBy、expiresAt、consumedAt | 单次授权 |
| Audit | id、action、runId、planId、at、outcome | 无凭据审计事件 |

## 一致性

写操作获取独占锁，状态写到临时文件后原子替换。提交前先持久化状态，进程崩溃后不重发。锁不自动抢占；异常退出后先确认没有存活进程，再由操作者处理锁文件。状态目录不得提交 Git，不保存 LWA 凭据或买家信息。
