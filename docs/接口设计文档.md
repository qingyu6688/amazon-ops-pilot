# 接口设计文档

传输为 MCP stdio。工具成功返回 JSON 文本内容，业务失败返回 isError=true 及 `{code,message}`。JSON-RPC/MCP 协议层由官方 SDK 处理。项目不对外开放 REST 路由。

## MCP 工具

| 工具 | 主要参数 | 作用与副作用 |
| --- | --- | --- |
| amazon_ops_status | 无 | 模式、范围、任务和能力矩阵 |
| amazon_workflow_start | sku | 本地创建新品任务 |
| amazon_workflow_get | runId | 任务、计划与当前用户技能 |
| amazon_workflow_advance | runId、evidence | 只完成当前阶段，有证据门槛 |
| amazon_workflow_refresh_compliance | runId、evidence | 完成实际复核后更新合规证据，不跳阶段 |
| amazon_custom_skill_read | name | 只读登记的项目内 SKILL.md |
| amazon_marketplaces_list | 无 | 卖家参与站点 |
| amazon_product_types_search | keywords | 当前站点商品类型 |
| amazon_product_type_definition_get | productType、attributeNames 可选 | 最新定义与字段细节 |
| amazon_catalog_get | asin | 目录商品事实 |
| amazon_listing_get | sku | 当前卖家和站点 Listing |
| amazon_inventory_get | sku、nextToken 可选 | FBA 库存分页，不创建货件 |
| amazon_reports_list | reportType、nextToken 可选 | 两类白名单报表元数据，不创建或下载 |
| amazon_listing_validate | sku、body | 标准 Schema 与平台预览，不发布 |
| amazon_listing_prepare | runId、body、acknowledgedWarnings 可选 | 创建限时发布计划 |
| amazon_listing_publish | planId | 唯一正式平台写工具；可能创建真实商品 |
| amazon_listing_verify | planId | 回读并持久化可售与问题，不把未知提交自动认定成功 |
| amazon_economics_calculate | unitPrice 及各项单件成本 | 单件贡献与简化盈亏平衡 ACoS |
| amazon_replenishment_calculate | 日销量、可售、可靠在途、交期、安全天数 | 补货规划，不采购 |

### body

```json
{"productType":"实际商品类型","requirements":"LISTING","attributes":{"字段名":"依该站点当前定义填写"}}
```

上面只说明结构，属性值不是通用生产格式。真实格式由 PTD 决定，不能直接提交。查看 examples/listing.demo.json 只能演练 mock。

### evidence

confirmed 必须 true；reference 非空并可追溯，notes 可选。compliance 额外要求 reviewedAt 和 policySources。格式通过不代表文件内容和商品合规事实已被工具证明。

## SP-API 映射

| API | 路径 | 方法 |
| --- | --- | --- |
| Sellers | /sellers/v1/marketplaceParticipations | GET |
| Product Type Definitions | /definitions/2020-09-01/productTypes 及 /{productType} | GET |
| Catalog Items | /catalog/2022-04-01/items/{asin} | GET |
| Listings Items | /listings/2021-08-01/items/{sellerId}/{sku} | GET / PUT |
| FBA Inventory | /fba/inventory/v1/summaries | GET |
| Reports | /reports/2021-06-30/reports | GET |

预览 PUT 带 mode=VALIDATION_PREVIEW，实际写入不带该参数。Listings 写操作仅传一个 marketplaceId。查询路径参数和查询串均编码。区域固定映射 NA/EU/FE 官方域名。

报表只允许 GET_SALES_AND_TRAFFIC_REPORT、GET_FBA_INVENTORY_PLANNING_DATA。首屏按类型/站点筛选，翻页 nextToken 是唯一查询参数；调用方保留原类型。FBA 库存分页需及时使用令牌，不保证过期后可继续。

## 权限与状态

不同 API 需相应 Amazon 应用角色、授权和卖家资格。配置范围是附加控制，不产生 Amazon 权限。MCP 的 readOnlyHint 只是宿主提示，真正限制由服务实现。

prepared → submitting → accepted / invalid / unknown。过期、摘要变更、配置变更和定义变更不能继续使用原计划。可售检查与提交状态独立。
