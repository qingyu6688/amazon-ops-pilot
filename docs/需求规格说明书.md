# 需求规格说明书

版本：1.0.0。维护备注：maorongkang@gmail.com。

## 用户与目标

面向亚马逊卖家、运营人员和接入 MCP 的 AI Agent。用一个主技能协调选品、合规、利润、采购、上架、履约、推广、日常运营、复盘；用确定性的工具执行已授权操作，并允许用户注册自己的子技能。

## 首版验收范围

- 可安装、可调用的 `amazon-ops-pilot` 主技能和按需读取的运营参考。
- 有证据记录与顺序约束的运营工作流；一条工作流对应一个 SKU、一个卖家和一个站点。
- stdio MCP：查询参与站点、商品类型与动态定义、目录、Listing、FBA 库存及非个人信息报表元数据。
- 新建 Listing：结构检查、动态 PTD 标准 Schema 检查、Amazon 验证预览、绑定草稿授权、提交和回读。
- 默认禁用正式写入；支持逐草稿授权及用户预先配置的限范围自动发布。
- 无凭据的完整本地模拟演示、自动化测试、中文部署与使用文档、GitHub CI。

## 边界

首版不自动扣款采购、不替代认证或税务判断、不控制卖家后台浏览器、不调用买家个人信息接口、不自动退款或发消息。不实现广告 API 写入、FBA 货件创建和已有 SKU 修改；主技能覆盖这些工作的规划、检查与人工交接。模拟数据不代表 Amazon 沙箱或生产验证。

## 自动化验收

禁写、越权、过期、验证错误、重复发布、未知提交结果、模拟与生产混用均必须被阻止；正式写请求不自动重试；`ACCEPTED` 不作为可售证明。用户自定义技能不能改写平台规则或扩大 MCP 权限。
