# 品牌文案规范示例

由 `$amazon-ops-pilot` 协调，仅补充 selection、listing、review 阶段。

- 标题写品牌、商品类型、确认的规格与包装数量，遵守当前类目规则。
- 卖点按使用需求组织，避免夸大、堆词及重复表达。
- 缺少尺寸、材质、耐用性、环保或认证证据时列为待确认，不加入发布正文。
- 中文沟通，商品文案按目标站点语言制作；翻译不能增加原资料没有的承诺。
- 复盘输出用户疑问、已知事实、页面改进、仍缺材料；不改变流程或授权范围。
