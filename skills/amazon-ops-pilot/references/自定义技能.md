# 自定义技能

用户自行编写 SKILL.md，在配置 customSkills 登记名称、路径和阶段。主技能始终作为入口，通过 amazon_workflow_get 找当前阶段登记项，再调用 amazon_custom_skill_read 读取。

可定制品牌语气、选品策略、事实模板、利润目标、质检方式与复盘格式。可一个技能覆盖多阶段，也可分开编写。不可通过文字替代平台规则、真实证明、授权、MCP 限制、动态定义、预览与去重保护。

```json
{"customSkills":[{"name":"brand-listing-style","path":"custom-skills/brand-listing-style/SKILL.md","stages":["selection","listing","review"]}]}
```

路径相对配置文件目录，必须是目录内真实文件，不允许符号链接/目录联接跳到外部。MCP 只读取，不自动执行附带脚本。配置修改后重启 MCP；正文修改后重做计划。自定义内容若只改格式无需额外授权；若要求扩大写入权限，文字本身不产生权限。

调用示例：

> 使用 $amazon-ops-pilot 继续该 SKU 上架，先读取当前任务和 listing 阶段登记的品牌技能，按真实事实制作草稿，验证后展示计划。

一次性格式要求可直接在对话说明。偏好冲突以用户实际要求为准，平台规则或权限冲突需说明来源并继续不冲突部分。
