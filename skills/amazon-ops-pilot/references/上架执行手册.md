# 上架执行手册

## 适用范围

首版只新建 SKU，requirements 为 LISTING；不支持已有 SKU 整项替换/PATCH、促销折扣或复杂业务报价。只允许配置范围内的常规 our_price，配送渠道也需明确登记。

## 执行步骤

1. amazon_ops_status 核对模式/权限，amazon_marketplaces_list 核对参与站点。
2. 读取任务及阶段用户技能，确认商品、品牌、图片权利、认证、采购与成本资料。
3. amazon_product_types_search 找实际类型；amazon_product_type_definition_get 先取字段名，再用 attributeNames 获取细节及条件约束，不能只看顶层 required。
4. 匹配已有目录时，用 amazon_catalog_get 核对完全相同 ASIN，不能因相似而匹配。
5. 按真实资料组织正文。图片需符合站点与类目要求并可被 Amazon 访问；本项目不托管图片、不自动检查像素或生成素材。
6. amazon_listing_validate 执行标准 Schema 检查与平台预览，修复错误并实际审阅警告。
7. amazon_listing_prepare 返回计划、摘要、期限和预览。展示站点、SKU、事实、图片、价格、数量和关键声明。
8. approval 使用用户的一次性计划授权，bounded 检查既有范围。MCP 没有自我授权工具。
9. amazon_listing_publish 仅提交 planId。正式请求前重取定义、重查 SKU、重新预览，不允许正文被替换。
10. accepted 仅报告平台已接收；amazon_listing_verify 回读对应站点问题与 BUYABLE，另外核实履约及前台展示。

## 异常

| 状态 | 处理 |
| --- | --- |
| WORKFLOW_GATE | 补齐真实前置证据，不新建任务绕过 |
| ATTRIBUTES_INVALID / PREVIEW_INVALID | 修复草稿再验证 |
| WARNINGS_UNREVIEWED | 查看预览，复核后按代码确认 |
| SKU_EXISTS | 停止整项写入，人工核查，不能换编号掩盖重复商品 |
| PLAN_EXPIRED / SCHEMA_CHANGED / CONFIG_CHANGED | 重建计划，旧授权不沿用 |
| 禁写、缺授权、越界 | 保留可审阅计划，使用已有合法范围或等待对应授权 |
| unknown / submitting | 回读、人工核对，不重发或另建计划 |
| accepted 但不可售 | 查异步问题和履约，不能反复 PUT |

本地校验不包含全部 Amazon 自定义词汇，平台预览也不能证明 IP、商品安全、税务及实际声明全部正确。准确报告已做检查和人工待办。
